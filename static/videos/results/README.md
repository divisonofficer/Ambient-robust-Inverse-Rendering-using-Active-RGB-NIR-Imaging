# Result clips

The clips are extracted from `static/videos/supplement_video 1.mp4` at 18 fps.

| Set | Object 1 | Object 2 | Object 3 |
| --- | --- | --- | --- |
| Synthetic | 37.833–49.833 s | 49.833–61.833 s | 61.833–73.833 s |
| Real | 73.833–85.833 s | 85.833–97.833 s | 97.833–109.833 s |

Each scene directory contains:

- `component-top-left.mp4`: upper-left component panel
- `component-top-right.mp4`: upper-right component panel
- `diffuse.mp4`: lower-left diffuse panel
- `specular.mp4`: lower-right specular panel
- `relighting-render.mp4`: large environment relighting panel
- `full-result.mp4`: the complete result layout for the 12-second scene

The component-panel labels change during some 12-second scenes, so the first two files are named by grid position rather than by a single material name.
